# Object - 객체지향 프로그래밍 학습

## 개요
객체지향 프로그래밍 관련 서적을 학습하고 예제 코드를 작성하는 프로젝트입니다.

## 기술 스택
- Java 21
- Gradle 8.5
- JUnit 5
- AssertJ

## 프로젝트 구조
```
object/
├── src/
│   ├── main/java/com/learning/object/
│   └── test/java/com/learning/object/
├── build.gradle
└── README.md
```

## 실행 방법
```bash
# 빌드
./gradlew build

# 테스트
./gradlew test
```
